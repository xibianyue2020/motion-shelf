# 安装说明

<Steps>

<Step>安装 Tailwind CSS</Step>

组件使用 Tailwind CSS 编写样式。请先按照官方安装指南，将 Tailwind CSS 添加到项目中。

<Step>安装 Motion</Step>

组件动效由 Motion 驱动。

<CodeBlock code={`npm install motion`} lang='bash' className='h-[52px]' />

<Step>添加样式工具函数</Step>

创建 `lib/utils.ts` 文件，用于合并和管理 Tailwind CSS 类名：

<CodeBlock filePath='lib/utils.ts' lang='ts' />

<Step>安装图标库</Step>

安装 Lucide React 图标库：

<CodeBlock code={`npm install lucide-react`} lang='bash' className='h-[52px]' />

<Step>完成</Step>

现在可以将动效组件添加到项目中了。

<InstallationCli value='text-effect' />
