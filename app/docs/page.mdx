# 动效组件总览

Motion Shelf 收录了 33 个动效组件和 96 个可交互示例，涵盖文字、数字、页面过渡与光影交互。浏览效果预览，查看示例源码，也可以复制代码用于自己的项目。

组件及示例基于 Motion Primitives，并随 Motion Shelf 本地打包。组件名称和说明已中文化，源码中的 API 标识保留原名，方便在代码中查找与使用。

## 开始使用

从左侧选择一个组件，查看它的动效说明、示例和安装方式。每个示例都提供预览与源码切换；点击“源码”可以复制完整示例。

## 组件分类

- **基础组件**：面板、轮播、弹窗、背景和视口动效。
- **文字动效**：逐字入场、文字轮播、变形、翻滚、扰码与流光效果。
- **数字动效**：数字滚动与翻牌效果。
- **交互动效**：坞栏、光晕、图片对比、滚动进度、聚光灯和倾斜效果。
- **工具栏**：动态伸缩与展开收起。
- **进阶效果**：磁吸、形变弹窗、形变浮层与渐进模糊。
